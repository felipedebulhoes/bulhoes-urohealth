## 🛠️ Como Utilizar os Runbooks

1. **Antes de editar qualquer código ou texto:** Identifique qual das habilidades se aplica à solicitação do usuário.
2. **Execute a lista de checagem do runbook:** Cada runbook contém pré-condições, etapas operacionais, regras invioláveis e comandos de validação.
3. **Validação Final:** Sempre garanta que a compilação passe sem erros (`npm run check`) e os testes sejam executados com sucesso (`npm test`).
